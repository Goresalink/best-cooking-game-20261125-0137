Warung Kilat — a fast-paced Indonesian street-food cooking game, by bang ndien. Orders land on the board, you build each dish from ingredients on the counter, cook it on the wok, and serve it before the customer's patience runs out. Four dishes, combos, tips, and a 150-second shift.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 — click ingredients (or press 1–8), press C to cook, click a finished plate then its order ticket to serve. P pauses, M mutes.
